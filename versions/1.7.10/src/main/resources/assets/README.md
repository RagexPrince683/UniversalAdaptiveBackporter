# UAB bundled asset credits

UAB retains the following inherited asset credits. Attribution does not transfer ownership or override the individual asset licenses. See the repository's THIRD_PARTY_NOTICES.md for Minecraft reference material and adapted code.

## Inherited project artwork

The inherited Et Futurum project logo was created by AstroTibs. It is retained as credited historical artwork; UAB's project name is Universal Adaptive Backporter.

## Barrels

- Steel and DarkSteel barrel and upgrade textures: krezhvick.
- Upgrade texture adjustments and stitched upgrade textures: Roadhog360.
- Other metal barrel textures: Tfarcenim, from [MetalBarrels](https://github.com/Tfarcenim/MetalBarrels/tree/1.16.x/src/main/resources/assets/metalbarrels/textures), public domain.

## Shulker boxes and ores

Roadhog360 adapted the Iron Shulker Box textures to the 1.11 color palette. Deepslate and raw-ore textures include work by moemaccornick, DarkBum and Roadhog360, with additional textures from their respective mods. Template-specific credits and the inherited reuse grant are recorded in templates/README.md at the repository root.
