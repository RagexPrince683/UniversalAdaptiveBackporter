# Modern content implementation matrix

Reference ceiling: released **Java Edition 1.21.11**. Source checkpoint: 2026-10-28.

This feature-family matrix records the inspected implementation and confirmed gaps. **The requested complete vanilla-content backport remains unfinished.** This is not an exhaustive item-by-item registry comparison or acceptance of every vanilla interaction. Registration, an asset and a successful build are insufficient evidence of functioning gameplay.

Statuses describe source coverage. **Fully implemented** means the behavior named by that row has an authoritative implementation, including native target behavior. **Adapted** means the feature is functional using deliberate legacy-compatible behavior, including native AI, conservative structure placement, adjusted recipes/loot, spawn rules, rates, and presentation. Those differences are not missing functionality. **Partially implemented** means a named, practical capability is absent or unfinished; the row must identify it. **Missing** means the necessary authoritative system/acquisition path was not found. **Requires engine adaptation** identifies an integration boundary. **Intentionally excluded** follows the scope restrictions. Runtime acceptance is separate.

Priorities: **P0** survival acquisition/correctness; **P1** missing functional content; **P2** extended behavior/presentation; **P3** excluded work. Source names below are relative to `versions/<target>/src/main/java/ganymedes01/etfuturum/`. Shared definitions/assets are under `common/`. The detailed [mob coverage](MOB_COVERAGE.md), [content catalog](CONTENT_CATALOG.md) and [world-generation reference](WORLD_GENERATION.md) supplement this matrix.

## Acceptance boundaries

Testing uses production JARs in disposable Java 8 Forge servers and hidden, muted clients. JDI installs a temporary tick/frame breakpoint, invokes actual production callbacks/native commands on the owning thread, removes the breakpoint and resumes the JVM. Accelerated callback counts verify state transitions, not performance or complete mouse-driven survival acceptance. Native framebuffer screenshots verify actual output. Test scripts, logs and worlds remain outside the repository.

The optional HEE/Enderlicious/Netherlicious runtime matrix, exhaustive custom water-color providers, old production-save migration and every mob interaction remain unaccepted until those combinations are actually run. Build and task responses report observed evidence separately from this source matrix.

Native cow, pig, chicken and wolf texture overrides are separately opt-in (`update_1_21_5.animal_appearances.enabled=false` by default). Gameplay and saved variants remain available with Spring to Life enabled; other mods retain their normal appearance/model ownership. Optional texture injections tolerate externally replaced render methods.
